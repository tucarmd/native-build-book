    Swift 101 — 10 ngày làm app Pomodoro¶

    Mọi đoạn code dưới đây đã được build và chạy test thật (Xcode 26.5, iPhone 17 Pro Max Simulator, 2026-10-14). Bản cuối Tuần 1 có 9 test xanh, bản cuối Tuần 2 cũng 9 test xanh. Cách học: tự gõ lại từng file (không copy-paste), đọc comment trong code, rồi trả lời phần 🧠 Tự kiểm tra. Bạn chưa trả lời được thì chưa sang ngày mới. Bị kẹt: hỏi Claude bằng skill /swift-ios-mentor để được giải thích, gõ /swift-ios-review để được review code. Mọi lệnh chạy trong thư mục mini-pomodoro/ ở gốc repo.

    Quy tắc Done mỗi ngày: make test xanh · make lint sạch · chạy app và tự nhìn thấy kết quả · commit.

    Day 1 — Setup 1 lệnh, không bấm Xcode settings¶

    Mục tiêu: có project chạy được trên Simulator chỉ bằng lệnh make. Vì sao làm vậy: xem 03 · Setup automation.

    3. Makefile: mỗi việc là một lệnh (giống mục scripts trong package.json của Angular). Chú ý: dòng lệnh bên dưới mỗi target phải bắt đầu bằng TAB, không được dùng dấu cách.

    # One command per job — no clicking around Xcode settings.  Usage: make <target>
APP        = Pomodoro
BUNDLE_ID  = com.learn.MiniPomodoro
SIM       ?= iPhone 17 Pro Max
DEST       = platform=iOS Simulator,name=$(SIM)
BUILD_DIR  = .build/xcode

.PHONY: setup doctor project build run test lint format clean

setup:            ## install tools + generate the Xcode project (run once)
    @command -v xcodegen >/dev/null || brew install xcodegen
    @command -v swiftlint >/dev/null || brew install swiftlint
    @$(MAKE) project

doctor:           ## check every tool the app needs
    @xcodebuild -version | head -1
    @xcode-select -p
    @command -v xcodegen  >/dev/null && echo "xcodegen  OK" || echo "xcodegen  MISSING → make setup"
    @command -v swiftlint >/dev/null && echo "swiftlint OK" || echo "swiftlint MISSING → make setup"
    @xcrun simctl list devices available | grep -q "$(SIM)" && echo "simulator '$(SIM)' OK" || echo "simulator '$(SIM)' MISSING → make run SIM=\"<a name from: xcrun simctl list devices>\""

project:          ## project.yml → Pomodoro.xcodeproj
    xcodegen generate

build: project
    xcodebuild build -project $(APP).xcodeproj -scheme $(APP) -destination '$(DEST)' -derivedDataPath $(BUILD_DIR) -quiet

run: build        ## build + install + open on the Simulator
    open -a Simulator
    xcrun simctl boot "$(SIM)" 2>/dev/null || true
    xcrun simctl install "$(SIM)" $(BUILD_DIR)/Build/Products/Debug-iphonesimulator/$(APP).app
    xcrun simctl launch "$(SIM)" $(BUNDLE_ID)

test: project     ## run the unit tests
    xcodebuild test -project $(APP).xcodeproj -scheme $(APP) -destination '$(DEST)' -derivedDataPath $(BUILD_DIR) 2>&1 | grep -E "✔|✘|error:|TEST (SUCCEEDED|FAILED)"

lint:             ## check code style + crash-prone code (like ESLint)
    swiftlint lint --strict

format:           ## auto-fix what can be fixed (like eslint --fix)
    swiftlint --fix

clean:
    rm -rf $(BUILD_DIR)

    Day 2 — Model: enum, struct, switch, test đầu tiên¶

    Đọc trước (15 phút): wiki Tuần 2 · Ngày 1 struct, Tuần 2 · Ngày 3 enum

    Swift ↔ TypeScript cần nhớ hôm nay

    Swift TypeScript / Angular
    let x = 1 / var x = 1 const x = 1 / let x = 1
    enum Phase { case focus … } type Phase = 'focus' \| … (nhưng switch bắt buộc phải xử lý đủ mọi case)
    struct (giá trị, gán là copy) object literal / interface (gán là chung tham chiếu)
    func seconds(for phase: Phase) -> Int seconds(phase: Phase): number
    Codable JSON.stringify / JSON.parse có kiểu

    File 1: Pomodoro/Models/Phase.swift

    import Foundation

/// The 3 kinds of session. An `enum` is a fixed list of choices — the compiler
/// forces every `switch` to handle all of them, so you can't forget one.
enum Phase: String, CaseIterable, Codable {
    case focus
    case shortBreak
    case longBreak

    var title: String {
        switch self {
        case .focus: return "Focus"
        case .shortBreak: return "Short break"
        case .longBreak: return "Long break"
        }
    }
}

    File 2: Pomodoro/Models/TimerSettings.swift

    import Foundation

/// How long each phase lasts. A `struct` = a plain value that gets copied, never shared.
/// `Codable` lets us turn it into JSON to save it.
struct TimerSettings: Codable, Equatable {
    var focusMinutes = 25
    var shortBreakMinutes = 5
    var longBreakMinutes = 15
    var sessionsBeforeLongBreak = 4

    func seconds(for phase: Phase) -> Int {
        switch phase {
        case .focus: return focusMinutes * 60
        case .shortBreak: return shortBreakMinutes * 60
        case .longBreak: return longBreakMinutes * 60
        }
    }
}

    Day 3 — Service: protocol, guard, try?, UserDefaults¶

    Đọc trước: Tuần 2 · Ngày 4 protocol, Tuần 6 · Ngày 4 persistence

    Ý tưởng: ViewModel không biết dữ liệu được lưu ở đâu. Nó chỉ biết một "hợp đồng" (protocol). Khi chạy app thật, ta đưa vào bản lưu thật. Khi chạy test, ta đưa vào bản giả. Giống Angular: inject một Service qua constructor, còn trong test thì useValue: mock.

    File 1: Pomodoro/Services/SettingsStore.swift

    import Foundation

/// Saves / loads settings. It is a `protocol` (= an interface) so tests can pass a fake.
protocol SettingsStore {
    func load() -> TimerSettings
    func save(_ settings: TimerSettings)
}

/// The real one: JSON inside UserDefaults (a small key-value file on the device).
struct UserDefaultsSettingsStore: SettingsStore {
    private let key = "timerSettings"

    func load() -> TimerSettings {
        // `guard … else` = "if this fails, leave early". `try?` turns an error into nil → no crash.
        guard let data = UserDefaults.standard.data(forKey: key),
              let settings = try? JSONDecoder().decode(TimerSettings.self, from: data) else {
            return TimerSettings() // first launch or broken data → defaults
        }
        return settings
    }

    func save(_ settings: TimerSettings) {
        guard let data = try? JSONEncoder().encode(settings) else { return }
        UserDefaults.standard.set(data, forKey: key)
    }
}

    Day 4 — ViewModel: toàn bộ logic + test¶

    Đọc trước: Tuần 7 · Ngày 1 MVVM, Tuần 6 · Ngày 3 async/await

    3 ý chính, đọc kỹ trước khi gõ: 1. Không trừ dần mỗi giây. Khi bấm Start, ta lưu endDate = bây giờ + thời gian còn lại. Mỗi giây chỉ tính lại endDate − bây giờ. Nhờ vậy app xuống nền 10 phút rồi quay lại vẫn hiện đúng giờ. 2. tick(now:) và start(now:) nhận thời gian qua tham số (mặc định là .now). Trong test, ta truyền một thời điểm giả, nên không cần chờ 25 phút thật. 3. @Observable: ViewModel thay đổi thuộc tính nào thì SwiftUI vẽ lại phần đọc thuộc tính đó. Không cần @Published, không cần subscribe như RxJS.

    File: Pomodoro/ViewModels/TimerViewModel.swift

    import Foundation
import Observation

/// ALL the timer logic lives here. The View only shows these values and calls these functions.
/// `@Observable` = when a property changes, SwiftUI redraws the views that read it.
@Observable
final class TimerViewModel {
    // MARK: - State the View reads (`private(set)` = the View can read but not change it)
    private(set) var phase: Phase = .focus
    private(set) var secondsLeft: Int
    private(set) var isRunning = false
    private(set) var completedFocusCount = 0 // in the current cycle, resets after a long break
    private(set) var settings: TimerSettings

    // MARK: - Private
    private var endDate: Date? // the clock time the phase ends — we never "count down" by subtracting
    private var loop: Task<Void, Never>?
    private let store: SettingsStore
    private let recorder: SessionRecorder
    private let notifier: Notifier

    init(store: SettingsStore, recorder: SessionRecorder, notifier: Notifier) {
        self.store = store
        self.recorder = recorder
        self.notifier = notifier
        let saved = store.load()
        settings = saved
        secondsLeft = saved.seconds(for: .focus)
    }

    // MARK: - Values computed for the View
    var timeText: String {
        String(format: "%02d:%02d", secondsLeft / 60, secondsLeft % 60)
    }

    var progress: Double {
        let total = settings.seconds(for: phase)
        guard total > 0 else { return 0 } // never divide by zero
        return 1 - Double(secondsLeft) / Double(total)
    }

    var buttonTitle: String {
        if isRunning { return "Pause" }
        return secondsLeft == settings.seconds(for: phase) ? "Start" : "Resume"
    }

    // MARK: - Actions (the View calls these)
    func startOrPause() {
        isRunning ? pause() : start()
    }

    /// `now` has a default value so the app just calls `start()`; tests pass a fake time.
    func start(now: Date = .now) {
        let end = now.addingTimeInterval(TimeInterval(secondsLeft))
        endDate = end
        isRunning = true
        notifier.requestPermission()
        notifier.schedule(title: "\(phase.title) finished", at: end)
        loop?.cancel()
        loop = Task { [weak self] in // `weak self`: the loop must not keep the ViewModel alive forever
            while !Task.isCancelled {
                try? await Task.sleep(for: .seconds(1))
                self?.tick()
            }
        }
    }

    func pause() {
        stop()
    }

    func reset() {
        stop()
        secondsLeft = settings.seconds(for: phase)
    }

    func skip() {
        stop()
        moveToNextPhase(finished: false)
    }

    /// Runs every second. Recomputes from `endDate`, so it is still right after the app was in the background.
    func tick(now: Date = .now) {
        guard isRunning, let endDate else { return }
        secondsLeft = max(0, Int(endDate.timeIntervalSince(now).rounded(.up)))
        if secondsLeft == 0 {
            stop()
            moveToNextPhase(finished: true, at: now)
        }
    }

    func updateSettings(_ newSettings: TimerSettings) {
        settings = newSettings
        store.save(newSettings)
        if !isRunning { secondsLeft = newSettings.seconds(for: phase) }
    }

    // MARK: - Private helpers
    private func stop() {
        isRunning = false
        endDate = nil
        loop?.cancel()
        loop = nil
        notifier.cancelAll()
    }

    private func moveToNextPhase(finished: Bool, at date: Date = .now) {
        switch phase {
        case .focus:
            if finished {
                completedFocusCount += 1
                recorder.record(minutes: settings.focusMinutes, at: date)
            }
            phase = completedFocusCount >= settings.sessionsBeforeLongBreak ? .longBreak : .shortBreak
        case .shortBreak:
            phase = .focus
        case .longBreak:
            completedFocusCount = 0
            phase = .focus
        }

    Day 6 — Thông báo khi hết giờ¶

    Ý tưởng: khi app ở nền, Task đếm giờ bị iOS tạm dừng. Vì vậy ngay lúc bấm Start, ta đặt trước một local notification cho đúng thời điểm endDate. Khi Pause, Reset hoặc Skip thì huỷ nó đi. ViewModel đã gọi notifier.schedule/cancelAll từ Day 4, nên hôm nay chỉ thêm bản thật, không sửa ViewModel. Đây là lợi ích của protocol.

    Sửa Pomodoro/Services/Notifier.swift thành:

    import Foundation
import UserNotifications

/// Shows "time's up" even when the app is in the background.
protocol Notifier {
    func requestPermission()
    func schedule(title: String, at date: Date)
    func cancelAll()
}

struct LocalNotifier: Notifier {
    private let id = "pomodoro.phaseEnd"

    func requestPermission() {
        // Denied is fine: the timer still works, there is just no banner.
        UNUserNotificationCenter.current().requestAuthorization(options: [.alert, .sound]) { _, _ in }
    }

    func schedule(title: String, at date: Date) {
        let content = UNMutableNotificationContent()
        content.title = title
        content.sound = .default
        let seconds = max(1, date.timeIntervalSinceNow) // the trigger crashes on 0 or less
        let trigger = UNTimeIntervalNotificationTrigger(timeInterval: seconds, repeats: false)
        UNUserNotificationCenter.current().add(UNNotificationRequest(identifier: id, content: content, trigger: trigger))
    }

    func cancelAll() {
        UNUserNotificationCenter.current().removePendingNotificationRequests(withIdentifiers: [id])
    }
}

/// Does nothing — used in Week 1 (before notifications exist) and in Previews.
struct NoopNotifier: Notifier {
    func requestPermission() {}
    func schedule(title: String, at date: Date) {}
    func cancelAll() {}
}

/// Writes a finished Focus session to history.
protocol SessionRecorder {
    func record(minutes: Int, at date: Date)
}

struct SwiftDataSessionRecorder: SessionRecorder {
    let context: ModelContext

    func record(minutes: Int, at date: Date) {
        context.insert(FocusSession(finishedAt: date, minutes: minutes))
        try? context.save() // a failed save loses one row — it must not crash the app
    }
}

/// Does nothing — used in Week 1 (before history exists) and in Previews.

struct HistoryView: View {

    @Environment(\.modelContext) private var context

    var body: some View {

            ForEach(sessions) { session in

                    Text(session.finishedAt, format: .dateTime.day().month().hour().minute())
                    Spacer()
                    Text("\(session.minutes) min").foregroundStyle(.secondary)
                }
            }
            .onDelete { offsets in
                for index in offsets { context.delete(sessions[index]) }
            }
        }

                ContentUnavailableView("No sessions yet", systemImage: "timer",
                                       description: Text("Finish a Focus session to see it here."))
            }
        }
        .navigationTitle("History")
    }
}
