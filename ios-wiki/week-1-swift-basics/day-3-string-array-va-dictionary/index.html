    Tuần 1 · Ngày 3 · String, Array và Dictionary¶

    Mục tiêu: Lưu và thao tác danh sách xe bằng String, Array, Dictionary, Set và dùng được map/filter/sorted.
    Thời lượng: 90 phút

    Khái niệm: String interpolation, Array, Dictionary, Set, filter / map / sorted / reduce, Closure cơ bản

    • Đã đọc xong
    • Đã làm hết bài tập

    1. String: giá trị, không phải object¶

    String trong Swift là struct (value type): gán cho biến khác sẽ sao chép giá trị. Bạn dùng + để nối, \(...) để nhúng giá trị, """ cho chuỗi nhiều dòng.

    Một điểm khác JS: bạn không truy cập ký tự bằng số nguyên (s[0] là lỗi) vì mỗi ký tự Unicode có thể gồm nhiều byte (ví dụ emoji, chữ có dấu tiếng Việt viết dạng tổ hợp). Hãy dùng first, last, prefix(n), suffix(n) hoặc duyệt bằng for ch in s.

    let make = "Toyota"
let model = "Camry"
let year = 2024

print("\(make) \(model) — \(year)")
print(make + " " + model)

print(make.count)                       // 6
print(make.uppercased())                // "TOYOTA"
print(make.hasPrefix("Toy"))            // true
print(make.contains("yo"))              // true
print(make.first!, make.prefix(3))      // T Toy

let note = """
Xe: \(make) \(model)
Năm: \(year)
"""
print(note)

    2. Array: danh sách có thứ tự¶

    Array<T> (viết gọn [T]) giữ phần tử cùng kiểu theo thứ tự, truy cập bằng chỉ số từ 0. Truy cập chỉ số ngoài phạm vi sẽ crash ngay (khác JS trả undefined), nên hãy kiểm tra isEmpty, count hoặc dùng first, last (trả về Optional).

    Array cũng là value type và dùng let/var như mọi giá trị khác: let thì không thêm/xóa được phần tử, var thì được. Các thao tác thường dùng: append, insert(_:at:), remove(at:), contains, sorted, reversed.

    var years = [2018, 2020, 2024]    // [Int]
years.append(2025)
years.insert(2019, at: 1)
years.remove(at: 0)

print(years.count, years.first ?? 0, years.last ?? 0)
print(years.contains(2020))       // true
print(years.sorted())             // tăng dần, không sửa mảng gốc
print(years.sorted(by: >))        // giảm dần

// print(years[10])               // CRASH: Index out of range
if let latest = years.max() {     // max() trả về Optional
    print("Mới nhất: \(latest)")
}

    3. Dictionary và Set¶

    Dictionary<Key, Value> (viết [Key: Value]) lưu cặp khóa–giá trị, không có thứ tự cố định. Đọc bằng khóa luôn trả về Optional vì khóa có thể không tồn tại. Gán dict[key] = nil sẽ xóa khóa đó. Có thể đưa giá trị mặc định bằng dict[key, default: 0].

    Set<T> giữ phần tử duy nhất, không thứ tự, kiểm tra contains rất nhanh; phù hợp để loại trùng hoặc kiểm tra thuộc tính.

    var modelByID: [String: String] = ["V001": "Camry", "V002": "Civic"]

let found = modelByID["V001"]          // Optional("Camry")
let missing = modelByID["V999"]        // nil
modelByID["V003"] = "Focus"            // thêm
modelByID["V002"] = nil                // xóa

var counts: [String: Int] = [:]
for make in ["Toyota", "Honda", "Toyota"] {
    counts[make, default: 0] += 1      // đếm theo hãng
}
print(counts)                          // ["Toyota": 2, "Honda": 1]

let unique = Set([2020, 2020, 2022])   // {2020, 2022}
print(unique.contains(2022))           // true

    4. map, filter, sorted, reduce và closure¶

    Đây là các hàm bậc cao giống map/filter/reduce của JS. Chúng nhận một closure (tương đương arrow function): { year in year >= 2020 }. Trong closure ngắn bạn có thể dùng $0, $1 cho tham số thứ nhất, thứ hai. • filter giữ lại phần tử thỏa điều kiện. • map biến đổi từng phần tử thành giá trị mới. • reduce gom thành một giá trị. • sorted(by:) sắp xếp theo tiêu chí. • compactMap giống map nhưng bỏ các kết quả nil (rất hợp để parse danh sách chuỗi). Tất cả đều trả về collection mới, không sửa mảng gốc.

    let years = [2017, 2020, 2022, 2019, 2025]

let recent = years.filter { $0 >= 2020 }            // [2020, 2022, 2025]
let labels = years.map { "Năm \($0)" }              // ["Năm 2017", ...]
let sum = years.reduce(0, +)                        // 10103
let newestFirst = years.sorted { $0 > $1 }

let inputs = ["2020", "abc", "2024"]
let parsed = inputs.compactMap { Int($0) }          // [2020, 2024]

    5. So sánh với TypeScript và lỗi thường gặp¶

    So sánh: • [Int] giống number[] nhưng các phần tử bắt buộc cùng kiểu. • Dictionary giống Record<string, T>/Map; đọc trả về Optional thay vì undefined. • Set giống Set của JS. • Mảng và dictionary là value type: gán sang biến khác tạo bản sao độc lập (JS thì chia sẻ tham chiếu).

    Lỗi thường gặp: 1. Truy cập array[index] ngoài phạm vi: crash "Index out of range". 2. Tưởng let array vẫn append được: lỗi vì let bất biến. 3. Dùng dict["key"]! mà khóa không có: crash. 4. Tưởng thứ tự khi duyệt Dictionary cố định: không đảm bảo, hãy sorted theo key nếu cần. 5. Dùng Dictionary [String: Any] thay vì struct rõ ràng cho dữ liệu nghiệp vụ.

    6. Tóm tắt¶

    • String, Array, Dictionary, Set đều là value type. • Dùng Array khi cần thứ tự, Dictionary khi tra cứu theo khóa, Set khi cần phần tử duy nhất. • Đọc Dictionary và first/max() trả về Optional. • Truy cập chỉ số mảng sai là crash, hãy kiểm tra trước. • filter, map, reduce, sorted, compactMap tạo collection mới, không sửa bản gốc. • Dữ liệu nghiệp vụ nên dùng struct (tuần 2), không dùng Dictionary lỏng lẻo.

    Bài tập¶

    Tự làm trước, rồi mới mở gợi ý / đáp án.

    Bài 1 — Lọc năm sản xuất¶

    Từ [2017, 2020, 2022, 2019, 2025], tạo mảng chỉ gồm các năm từ 2020 trở đi, sau đó tạo mảng chuỗi dạng "Năm 2020".

    Gợi ý Dùng filter rồi map. Hai bước có thể nối chuỗi lệnh.
    Đáp án 
    let years = [2017, 2020, 2022, 2019, 2025]
let labels = years
    .filter { $0 >= 2020 }
    .map { "Năm \($0)" }
print(labels)   // ["Năm 2020", "Năm 2022", "Năm 2025"]
    **Giải thích:** `filter` giữ phần tử thỏa điều kiện, `map` biến đổi từng phần tử. Mảng gốc `years` không đổi.

    Bài 2 — Khóa không tồn tại¶

    Vì sao vehicle["year"] không trả về String mà trả về String?? Viết đoạn xử lý an toàn khi khóa vắng mặt.

    Gợi ý Dictionary không đảm bảo khóa có tồn tại, nên kiểu trả về phải biểu diễn trường hợp không có.
    Đáp án 
    let vehicle = ["make": "Toyota"]

if let year = vehicle["year"] {
    print("Năm: \(year)")
} else {
    print("Chưa có năm")
}

let make = vehicle["make"] ?? "Không rõ"
    **Giải thích:** Optional buộc bạn xử lý trường hợp khóa không tồn tại ngay trong code. `if let` mở Optional nếu có giá trị, `??` cung cấp giá trị mặc định.

    Bài 3 — Đếm xe theo hãng¶

    Cho ["Toyota", "Honda", "Toyota", "Ford", "Honda", "Toyota"], đếm số xe theo từng hãng bằng Dictionary. In hãng có nhiều xe nhất.

    Gợi ý Dùng counts[make, default: 0] += 1, sau đó dùng max(by:) trên dictionary.
    Đáp án 
    let makes = ["Toyota", "Honda", "Toyota", "Ford", "Honda", "Toyota"]
var counts: [String: Int] = [:]
for make in makes {
    counts[make, default: 0] += 1
}

if let top = counts.max(by: { $0.value < $1.value }) {
    print("\(top.key): \(top.value)")   // Toyota: 3
}
    **Giải thích:** Subscript có `default:` cho phép tăng bộ đếm mà không cần kiểm tra khóa tồn tại. `max(by:)` trả về Optional vì dictionary có thể rỗng.

    Bài 4 — Parse danh sách chuỗi¶

    Có ["2020", "abc", "2024", ""]. Tạo mảng [Int] chỉ gồm các giá trị hợp lệ và tính tổng.

    Gợi ý compactMap loại bỏ nil. Int(String) trả về Int?.
    Đáp án 
    let raw = ["2020", "abc", "2024", ""]
let years = raw.compactMap { Int($0) }   // [2020, 2024]
let total = years.reduce(0, +)           // 4044
    **Giải thích:** `compactMap` vừa biến đổi vừa bỏ qua kết quả `nil`, đây là cách ngắn gọn để làm sạch dữ liệu nhập.
