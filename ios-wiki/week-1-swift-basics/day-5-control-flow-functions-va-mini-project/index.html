    Tuần 1 · Ngày 5 · Control flow, functions và mini project¶

    Mục tiêu: Kết hợp điều kiện, vòng lặp, function và collections để hoàn thành phiên bản đầu của Vehicle Inventory.
    Thời lượng: 90–120 phút

    Khái niệm: if / switch, for-in / while, Ranges, Functions, Argument labels, Default values, Tuple return

    • Đã đọc xong
    • Đã làm hết bài tập

    1. Điều kiện: if và switch¶

    Điều kiện của if bắt buộc là Bool: không có truthy/falsy như JS (if count { } với Int là lỗi). Dấu ngoặc đơn quanh điều kiện không cần thiết, nhưng dấu { } là bắt buộc.

    switch mạnh hơn nhiều so với JS: • Phải exhaustive: xử lý hết mọi khả năng bằng case hoặc default. • Không "rơi xuống" case kế tiếp, nên không cần break. • Một case có thể gộp nhiều giá trị, khớp khoảng (range) hoặc kèm điều kiện where. • if và switch còn dùng như biểu thức gán giá trị từ Swift 5.9.

    let year = 2022

if year >= 2023 {
    print("Mới")
} else if year >= 2018 {
    print("Khá mới")
} else {
    print("Cũ")
}

let status = "connecting"
switch status {
case "connected":
    print("Ready")
case "connecting", "reconnecting":      // gộp nhiều giá trị
    print("Đang kết nối")
default:
    print("Unavailable")
}

let battery = 42
switch battery {
case 0..<20:    print("Pin yếu")
case 20...80:   print("Bình thường")
case let x where x > 80:  print("Đầy: \(x)")
default:        print("Không hợp lệ")
}

    2. Vòng lặp và range¶

    for-in duyệt collection hoặc range. Range đóng 1...5 gồm cả 5, range nửa mở 0..<5 không gồm 5. Dùng _ khi không cần biến lặp. while và repeat-while dùng khi chưa biết số lần lặp.

    Dùng enumerated() khi cần cả chỉ số lẫn phần tử, break/continue như các ngôn ngữ khác. Với phép biến đổi/lọc đơn giản, map/filter (bài 3) thường gọn hơn vòng lặp thủ công.

    let years = [2017, 2020, 2024]

for year in years {
    print(year)
}

for (index, year) in years.enumerated() {
    print("\(index + 1). \(year)")
}

for i in 1...3 { print("Lần \(i)") }      // 1, 2, 3
for i in 0..<years.count { print(i) }     // 0, 1, 2

var retry = 0
while retry < 3 {
    retry += 1
}

    3. Function: khai báo, argument label, giá trị mặc định¶

    Function khai báo bằng func, tham số có kiểu rõ ràng, kiểu trả về sau ->. Nếu không trả về gì thì bỏ ->. Thân hàm một biểu thức có thể bỏ return.

    Đặc trưng của Swift là argument label: mỗi tham số có tên dùng khi gọi (external) và tên dùng trong thân hàm (internal). Cú pháp func find(by id: String) được gọi là find(by: "V1"), đọc như một câu. Dùng _ để bỏ label khi gọi. Tham số có thể có giá trị mặc định. Hàm có thể trả nhiều giá trị bằng tuple.

    func isRecent(year: Int) -> Bool {
    year >= 2020                         // một biểu thức: bỏ return
}

func findVehicle(by id: String, in list: [String]) -> String? {
    list.first { $0 == id }
}
let hit = findVehicle(by: "V001", in: ["V001", "V002"])   // label đọc như câu

func recentYears(_ years: [Int], from cutoff: Int = 2020) -> [Int] {
    years.filter { $0 >= cutoff }
}
print(recentYears([2017, 2021]))                // dùng mặc định 2020
print(recentYears([2017, 2021], from: 2018))

func stats(of values: [Double]) -> (min: Double, max: Double)? {
    guard let lo = values.min(), let hi = values.max() else { return nil }
    return (lo, hi)
}
if let s = stats(of: [3.5, 1.2, 9.9]) { print(s.min, s.max) }

    4. Mini project: Vehicle Inventory (không có UI)¶

    Mục tiêu: gom mọi thứ của tuần 1 vào một chương trình console nhỏ. Yêu cầu: 1. Có danh sách ít nhất 5 năm sản xuất; lọc những năm từ 2020 trở đi. 2. Có Dictionary ID → model, và hàm findModel(id:) trả về Optional. 3. Hàm tính năm trung bình, an toàn với mảng rỗng (trả Double?). 4. In báo cáo: tổng số xe, số xe mới, model tìm được hoặc "Not found".

    Cách làm: viết từng hàm nhỏ, mỗi hàm một nhiệm vụ, hàm nào cũng gọi thử bằng print trước khi ghép lại. Mẹo debug: đặt breakpoint trong Xcode hoặc dùng print để xem giá trị trung gian.

    let years = [2017, 2020, 2022, 2019, 2025]
let models = ["V001": "Camry", "V002": "Civic"]

func recentYears(from years: [Int], cutoff: Int = 2020) -> [Int] {
    years.filter { $0 >= cutoff }
}

func findModel(id: String) -> String? { models[id] }

func averageYear(_ years: [Int]) -> Double? {
    guard !years.isEmpty else { return nil }
    return Double(years.reduce(0, +)) / Double(years.count)
}

let recent = recentYears(from: years)
print("Tổng: \(years.count), mới: \(recent.count)")
print("Trung bình: \(averageYear(years) ?? 0)")
print("V002: \(findModel(id: "V002") ?? "Not found")")
print("V999: \(findModel(id: "V999") ?? "Not found")")

    5. Functional programming: hàm là giá trị¶

    Swift là ngôn ngữ đa mô hình: bạn có thể viết theo kiểu hướng đối tượng, hướng protocol hoặc functional. Phần functional đặc biệt hữu ích khi biến đổi dữ liệu, và dev TypeScript đã quen sẵn nhiều thứ. Các ý chính: • Hàm là "công dân hạng nhất" (first-class): gán vào biến, truyền làm tham số, trả về từ hàm khác. Kiểu hàm viết (Int) -> Int. • Hàm bậc cao (higher-order): hàm nhận hoặc trả về hàm, ví dụ map, filter, reduce, sorted(by:), flatMap, compactMap. • Hàm thuần (pure function): cùng đầu vào luôn cho cùng đầu ra và không có tác dụng phụ (không sửa biến ngoài, không ghi file, không gọi mạng). Dễ test, dễ suy luận, an toàn khi chạy song song. • Bất biến (immutability): ưu tiên let và struct; biến đổi bằng cách tạo giá trị mới thay vì sửa tại chỗ. • Closure: hàm không tên, "bắt" biến xung quanh. Cú pháp trailing closure và $0, $1 làm chuỗi biến đổi rất gọn.

    Nguyên tắc thực dụng: dùng phong cách functional cho phần biến đổi dữ liệu (lọc, nhóm, tính tổng) và giữ phần có tác dụng phụ (IO, UI, state) ở rìa, tách riêng.

    // 1. Hàm là giá trị: kiểu hàm và gán vào biến
let double: (Int) -> Int = { $0 * 2 }
func apply(_ value: Int, using transform: (Int) -> Int) -> Int { transform(value) }
print(apply(21, using: double))                 // 42

// 2. Hàm trả về hàm
func makeAdder(_ n: Int) -> (Int) -> Int { { $0 + n } }
let addFive = makeAdder(5)
print(addFive(10))                              // 15

// 3. Ghép (compose) hai hàm nhỏ
func compose<A, B, C>(_ f: @escaping (A) -> B, _ g: @escaping (B) -> C) -> (A) -> C { { g(f($0)) } }
let doubleThenAddFive = compose(double, addFive)
print(doubleThenAddFive(10))                    // 25

// 4. Chuỗi biến đổi dữ liệu, không sửa mảng gốc
struct Vehicle { let make: String; let year: Int; let tags: [String] }
let fleet = [
    Vehicle(make: "Toyota", year: 2024, tags: ["ev", "city"]),
    Vehicle(make: "Honda", year: 2018, tags: ["city"]),
    Vehicle(make: "Ford", year: 2022, tags: ["suv", "city"])
]
let recentMakes = fleet
    .filter { $0.year >= 2020 }                 // lọc
    .map(\.make)                                // biến đổi (key path làm hàm)
    .sorted()                                   // sắp xếp
print(recentMakes)                              // ["Ford", "Toyota"]

let allTags = Set(fleet.flatMap(\.tags))        // flatMap: làm phẳng mảng lồng nhau
let totalYears = fleet.reduce(0) { $0 + $1.year }

// 5. flatMap/map trên Optional (liên quan null-safety)
let input: String? = "2024"
let year: Int? = input.flatMap { Int($0) }      // Optional chaining kiểu functional
let label = year.map { "Năm \($0)" } ?? "Không rõ"

    6. So sánh với TypeScript, và lỗi thường gặp¶

    So sánh: • switch của Swift bắt buộc exhaustive và không fall-through; JS thì ngược lại. • Argument label không có trong TypeScript (thường dùng object tham số); Swift cho code gọi dễ đọc hơn. • Hàm trả nhiều giá trị bằng tuple thay cho object literal. • Swift có overload theo kiểu và label, TypeScript thì không.

    Lỗi thường gặp: 1. Viết điều kiện không phải Bool (ví dụ if count). 2. switch thiếu default: lỗi "must be exhaustive". 3. Quên label khi gọi: findVehicle("V001") thay vì findVehicle(by: "V001"). 4. Chia cho list.count khi mảng rỗng: chia cho 0 làm crash với số nguyên hoặc ra NaN với Double. 5. Dùng 0...count thay vì 0..<count gây index out of range. 6. Tạo hàm quá lớn làm nhiều việc; hãy tách để dễ test.

    7. Tóm tắt và checkpoint tuần 1¶

    • if cần Bool; switch phải exhaustive, không fall-through, hỗ trợ range và where. • for-in với collection và range (... đóng, ..< nửa mở). • Function có argument label, giá trị mặc định, có thể trả tuple. • Hàm nhỏ, một nhiệm vụ, kiểu trả về thể hiện rõ khả năng thất bại (Optional).

    Checklist trước khi sang tuần 2: ☐ Giải thích được let khác var và vì sao nên ưu tiên let. ☐ Biết vì sao Int + Double lỗi và cách sửa. ☐ Dùng được filter/map/reduce. ☐ Xử lý Optional bằng if let, guard let, ?? mà không dùng !. ☐ Hoàn thành Vehicle Inventory và chạy không crash với đầu vào rỗng. • Functional: hàm là giá trị, hàm bậc cao (map/filter/reduce/flatMap), hàm thuần và bất biến cho phần biến đổi dữ liệu.

    Bài tập¶

    Tự làm trước, rồi mới mở gợi ý / đáp án.

    Bài 1 — Tính trung bình an toàn¶

    Viết hàm nhận [Double] và trả về Double?. Nếu mảng rỗng thì trả về nil. Gọi thử với [] và [10, 20].

    Gợi ý Kiểm tra isEmpty trước khi chia. Tổng chia Double(count).
    Đáp án 
    func average(_ values: [Double]) -> Double? {
    guard !values.isEmpty else { return nil }
    return values.reduce(0, +) / Double(values.count)
}

print(average([]) ?? 0)         // 0
print(average([10, 20]) ?? 0)   // 15.0
    **Giải thích:** Mảng rỗng không có trung bình hợp lệ, nên `Optional` diễn đạt đúng hơn trả về 0. Cần `Double(values.count)` vì Swift không chia `Double` cho `Int`.

    Bài 2 — Phân loại bằng switch¶

    Viết hàm category(forYear:) trả về "Cũ" (trước 2015), "Trung bình" (2015–2019), "Mới" (2020 trở đi). Dùng switch với range.

    Gợi ý Dùng case ..<2015, 2015...2019 và 2020... (range một phía).
    Đáp án 
    func category(forYear year: Int) -> String {
    switch year {
    case ..<2015:     return "Cũ"
    case 2015...2019: return "Trung bình"
    default:          return "Mới"
    }
}
print(category(forYear: 2018))   // Trung bình
    **Giải thích:** Range một phía (`..<2015`) gọn hơn so với `Int.min..<2015`. `default` bảo đảm switch exhaustive.

    Bài 3 — Argument label và giá trị mặc định¶

    Viết hàm describe(make:model:year:) trong đó year mặc định 2024, trả về chuỗi "Toyota Camry (2024)". Gọi hàm với và không có year.

    Gợi ý Tham số có giá trị mặc định dùng cú pháp year: Int = 2024.
    Đáp án 
    func describe(make: String, model: String, year: Int = 2024) -> String {
    "\(make) \(model) (\(year))"
}

print(describe(make: "Toyota", model: "Camry"))
print(describe(make: "Honda", model: "Civic", year: 2020))
    **Giải thích:** Với giá trị mặc định, người gọi chỉ phải viết các tham số khác mặc định. Label bắt buộc khi gọi giúp đọc code như một câu.

    Bài 4 — Vehicle Inventory mini challenge¶

    Hoàn thiện báo cáo: từ mảng năm [2017, 2020, 2022, 2019, 2025], in số xe mới (từ 2020), năm mới nhất, và "Not found" cho một ID không tồn tại. Giải thích vì sao nên tách logic thành function.

    Gợi ý Kết hợp filter, max() và dictionary lookup với ??. Function cho logic có thể gọi lại và kiểm thử độc lập.
    Đáp án 
    let years = [2017, 2020, 2022, 2019, 2025]
let models = ["V001": "Camry"]

func recentYears(from years: [Int]) -> [Int] {
    years.filter { $0 >= 2020 }
}

print("Xe mới: \(recentYears(from: years).count)")
print("Năm mới nhất: \(years.max() ?? 0)")
print("V009: \(models["V009"] ?? "Not found")")
    **Giải thích:** Tách function làm rõ input/output, tránh lặp code và sau này có thể viết unit test cho từng hàm. `max()` và dictionary lookup trả về Optional nên dùng `??` để có giá trị mặc định.

    Bài 5 — Tư duy functional¶

    Cho let years = [2017, 2020, 2022, 2019, 2025]. Bằng một chuỗi filter/map/reduce (không dùng vòng lặp for), tính tổng của các năm từ 2020 trở đi sau khi cộng thêm 1 cho mỗi năm. Sau đó viết hàm makeMultiplier(_:) trả về một hàm nhân với hằng số.

    Gợi ý filter lấy năm ≥ 2020, map cộng 1, reduce(0, +). Hàm trả về hàm có kiểu (Int) -> Int.
    Đáp án 
    let years = [2017, 2020, 2022, 2019, 2025]
let total = years
    .filter { $0 >= 2020 }
    .map { $0 + 1 }
    .reduce(0, +)                  // (2020+2022+2025) + 3 = 6070

func makeMultiplier(_ factor: Int) -> (Int) -> Int {
    { $0 * factor }
}
let triple = makeMultiplier(3)
print(total, triple(7))            // 6070 21
    **Giải thích:** Mỗi bước là một hàm thuần tạo giá trị mới, mảng gốc không đổi. `makeMultiplier` trả về closure bắt `factor`, đây là ví dụ hàm bậc cao và closure phối hợp.
